# futura – Plataforma de inscrições

Página pública de inscrição da **futura – Plataforma de Dança Contemporânea** (Instável – Centro Coreográfico).
Esta pasta só contém a página (HTML, CSS e JavaScript). Os dados ficam numa folha Google privada e o script da Google responde à página.

- `index.html` · página pública
- `css/` · identidade visual (`tokens.css`) e estilos
- `js/config.js` · **endereço do script da Google (preencher)**
- `js/` · textos PT/EN, comunicação com o script e lógica da página
- `assets/` · logótipo, favicon e a letra Fustat (`assets/fonts/`)

Nenhum dado pessoal deve ser guardado neste repositório.
